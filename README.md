# PulseColor

PulseColor меняет оформление Яндекс Музыки в PulseSync под текущий трек: цвета интерфейса следуют обложке, на фоне движется волна, а строки песни реагируют на звук.

> **Видео общего обзора:** здесь будет демонстрация переключения треков, смены цветов и работы волны.

## Раскраска и фон

Цвета можно брать из обложки альбома, фотографии исполнителя или заданного вручную цвета. Доступны чёрно-белая палитра, фоновое изображение и настройка плотности панелей. Светлое и тёмное оформление используют разные цвета текста и кнопок.

## Волна

Три варианта используют общий анализ звука:

- **Стандартная** — объёмная 3D-волна.
- **Круговая** — плоская волна вокруг центра.
- **По краям** — свечение вдоль краёв окна.

Реакцию можно настроить по звуку или по доступному темпу BPM. Чувствительность, интенсивность, плавность и скорость движения регулируются отдельно.

Палитра выбирается независимо от формы: один цвет, основной со случайным акцентом на время трека, цвета обложки или контрастные переливы. В режиме «Цвета обложки» используются различимые яркие и тёмные оттенки без ограничения тремя цветами; близкие оттенки и блеклые средние тона отсеиваются.

> **Видео:** здесь будет сравнение трёх видов волн на одном фрагменте музыки.

## «Моя волна» и интерфейс

Можно оставить полное оформление «Моей волны» или включить режим **«Только плеер»**, скрывающий дополнительные рекомендации и подписи. Настройки «Моей волны» при этом не должны блокировать управление музыкой.

В плеер добавлены быстрые кнопки очереди и текста. Их действия выполняет нативный интерфейс Яндекс Музыки; доступность текста отслеживается по его живому меню. Обычное троеточие остаётся доступным.

Панели подстраиваются под размеры окна. При отключённой настройке «всегда расширенная» боковая панель занимает пространство до нижнего края. На «Моей волне» dev располагается рядом с версией, если включён режим разработчика. Без dev версия остаётся в углу блока с отступом от рамки. На других страницах положение dev — штатное.

Для обычных страниц предусмотрены анимации появления и переходов. В настройках очередь появления и ожидание загрузки отключены: элементы доступны сразу после отрисовки Яндекс Музыкой.

## Полноэкранный плеер и текст

Доступны стандартное оформление, **Tweaked YM Design** и **Cover2Anim**. Интеграция Cover-Tweaked находится внутри PulseColorVisual — отдельный аддон для неё не требуется.

Текст может увеличиваться и менять цвет в ответ на музыку. Реакция учитывает весь доступный частотный диапазон, быстрые удары и протяжные звуки, а не только бас.

- Прыжки и изменение цвета отключаются независимо.
- Амплитуда задаётся от **1 до 10**: 1 сохраняет базовую амплитуду, каждый следующий шаг умножает её на 1,1.
- Цвет не зависит от выбранной амплитуды.
- Для перевода **LyricsTranslation** применяется та же реакция активной строки. Сам перевод предоставляет отдельный аддон.
- Размытие и прозрачность соседних строк настраиваются отдельно.

Часть полноэкранных возможностей и эффектов текста требует подписки PulseSync. Проверка доступа сохранена; наличие кода в репозитории не снимает ограничения.

## Настройки и производительность

Все пользовательские настройки находятся в **PulseColorVisual**, в том числе отдельная категория «Полноэкранный». У CSS-темы собственной панели настроек нет.

Можно выбрать профиль производительности, качество рендера, плотность пикселей и оформление эффектов. Фактическое разрешение зависит от размера окна, DPR и выбранного качества. Профили производительности не перезаписывают сохранённые пользовательские значения.

## Из чего состоит PulseColor

Для работы нужны три компонента:

1. [PulseColor](https://github.com/Imperiadicks/PulseColor) — CSS-тема, оформление и ресурсы.
2. [PulseColorVisual](https://github.com/Imperiadicks/PulseColorVisual) — настройки, цвета, волны, анимации и полноэкранный интерфейс.
3. [PulseColorAudioCore](https://github.com/Imperiadicks/PulseColorAudioCore) — анализ звука для визуальных эффектов.

Добавьте компоненты в PulseSync, включите оба web-addon и выберите тему PulseColor. Настраивать оформление нужно в PulseColorVisual.

### Экспериментальное распознавание

В рабочей версии также есть отдельная экспериментальная функция распознавания вокала через Whisper. Она не нужна для волн, прыжков, изменения цвета или отображения нативного текста.

Модель запрашивается после ручного включения. Сейчас функция не считается готовой: наблюдалась ошибка загрузки `Failed to fetch`, а успешное распознавание не подтверждено. Не путайте её с обычным анализом частот. В вариантах архива «без нейронки» этот фрагмент исключён.

## Разработка

Репозитории размещаются рядом, под именами PulseColor, PulseColorVisual и PulseColorAudioCore. Нужны Node.js и Yarn; требования к версии Node.js указаны в package.json каждого проекта.

В каждом проекте:

```bash
yarn install
yarn typecheck
yarn test
yarn build
```

Из репозитория темы собрать все три компонента:

```bash
node scripts/build-all.mjs
```

Для сборки с локальной установкой в PulseSync:

```bash
node scripts/build-all.mjs --sync
```

Сборки находятся в dist каждого проекта. node_modules, dist, личные настройки и временные браузерные профили не должны попадать в Git.
