[уведомления и границы прав](THIRD-PARTY-NOTICES.md).

Основной пакет — тема `PulseColor` (`theme`). Её функциональная зависимость —
`PulseColor Runtime` (`script`) в контексте страницы ЯМ через официальный `pulsesyncApi`.
Предыдущий проект сохранён рядом в `PulseColorArchive`, вместе с историей Git и незакоммиченными изменениями.

## Что перенесено

Сохранены оформление, волна, Cover2Anim, Tweaked YM Design, полноэкранный текст,
31 настройка и полные модели голосового анализа. Это Full-версия, не Lite.

Точка входа Runtime написана на TypeScript; визуальные модули остаются JavaScript-модулями.
Это не завершённая перепись интерфейса на React.

У темы сохранён прежний ID `419c58cb-75c5-48bf-b053-933f3b81190f`.
В её `dependencies` указан Runtime с отдельным ID `a8a17b79-c9d3-4af7-a984-7a2037a205df`.
Тема содержит CSS, но не запускает JavaScript-движки. Runtime запускает их один раз и
останавливает при смене темы. Обратной зависимости нет.

Все 31 настройка доступны в `PulseColor Runtime`. При первой установке Runtime получает сохранённые
значения прежнего PulseColor; последующие установки не перезаписывают его настройки.

## Структура

- `addon.config.mjs`, `src/theme.ts`, `vite.config.ts`: тема и CSS-сборка.
- `runtime/addon.config.mjs`, `src/main.script.ts`, `vite.runtime.config.ts`: зависимость Runtime и её IIFE-сборка.
- `src/runtime/`: адаптер официального API, внутренний захват PCM, запуск и очистка ресурсов.
- `src/modules/`: перенесённые модули оформления, аудио, голоса, волны и текста.
- `src/settings.ts` и `src/settings.catalog.json`: экспорт настроек с сохранением прежних ID и категорий.
- `addon/`: статические файлы темы.
- `runtime/addon/Assets/Vocals/`: полные модели и браузерные вычислительные библиотеки; в тему они не дублируются.

TSX нужен для JSX/React-интерфейса; логика может быть на TS/JS, вычислительные модули — на Rust/WASM.
Внутренние файлы в `src/modules/` собираются вместе с аддоном: это не отдельно публикуемые модули SDK.

## Проверка и сборка

```bash
yarn install
yarn typecheck
yarn test
yarn build
```

`yarn build` создаёт два пакета в `dist/<theme-id>` и `dist/<runtime-id>` без установки.
`yarn build:theme` и `yarn build:runtime` собирают их отдельно.
`yarn build:sync` устанавливает оба пакета, сначала зависимость, сохраняя настройки.
`yarn dev` пересобирает и устанавливает оба пакета. После сборки обновите список дополнений
и перевключите Runtime; после изменений CSS перевыберите тему.
Dev-endpoint для горячей перезагрузки `web-addon` не используется для `script`.
В PulseSync выбирайте `PulseColor` как тему и включайте зависимость `PulseColor Runtime`.
Для релиза публикуются оба пакета; локальная сборка не публикует их в каталог автоматически.
Архивная версия и новая тема используют один ID: устанавливать их одновременно не следует.

Дополнительные браузерные проверки: `node scripts/check-cover-renderer.mjs` и
`node scripts/check-fullscreen-lyrics.mjs`.

## Непрерывный звук для нейросервиса

Нейронные модели не урезаны. Для их работы нужен непрерывный PCM-поток.
Runtime получает аудиоэлементы из `pulsesyncApi.getState()` и захватывает их копии
через `captureStream()` внутри аддона. Один собственный AudioContext обеспечивает
быстрый анализ для битов и непрерывный AudioWorklet-поток для полных нейромоделей.
Выход ветки анализа беззвучен. Внешнего процесса, PipeWire-захвата, микрофона и
патчинга `app.asar` или мода нет. В отсутствие свежего PCM нейронный результат
не выдаётся за успешное распознавание.
Ограничения и проверки описаны в [docs/SCRIPT_AUDIO.md](./docs/SCRIPT_AUDIO.md).

Документация прежнего проекта сохранена в [docs/LEGACY.md](./docs/LEGACY.md).
Большое описание алгоритмов будет подготовлено перед релизом.
