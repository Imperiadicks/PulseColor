# PulseColor — три проекта

Зависимости: **PulseColor → PulseColorVisual → PulseColorAudioCore**.

- **PulseColor** — CSS-тема, метаданные, изображения и лицензии. Пакет не содержит запускаемого JS, настроек или `handleEvents.json`.
- **PulseColorVisual** — владелец настроек, раскраска, три вида волн, анимации интерфейса, Cover2Anim, Tweaked и полноэкранный текст. Отдельный Cover-Tweaked больше не нужен.
- **PulseColorAudioCore** — SDK-анализ звука и ограниченный канал кадров/диагностики; не читает хранилище Visual или темы.

У каждого проекта собственные сборка, Git и `dist/<id>/`.
`node build-all.mjs` собирает все три; `node build-all.mjs --sync` сначала собирает, затем устанавливает их.
Из отдельного проекта: `yarn typecheck`, `yarn test`, `yarn build:sync`.

## Настройки

Каталог и SDK-схема: `PulseColorVisual/src/settings.catalog.json` и `src/settings.ts`.
В настройках PulseSync открывайте **PulseColorVisual**, не тему.
Первое локальное обновление переносит актуальный файл темы в Visual, даже если у Visual остался старый файл.
Индексы старых селекторов преобразуются в значения SDK. Маркер `.pulsecolor-visual-settings-v2` защищает последующие изменения Visual от повторного импорта.
После переноса тема больше не публикует настройки и не хранит их в установленном пакете.
Резервная копия исходных установленных пакетов хранится вне addons.

Visual публикует только разрешённые примитивные настройки в общем DOM.
Историческое имя канала `pulsecolor-theme-settings-v1` сохранено; поле `theme` теперь содержит ID владельца Visual.
Профили производительности вычисляются в Visual без перезаписи пользовательских значений.
AudioCore подписывается на этот ограниченный канал, не на чужой store.

## Звук и fullscreen

Visual использует один клиент AudioCore для волны и fullscreen; второй аудиодвижок не создаётся.
`PulseColor.audio.getFrame()` возвращает свежий кадр, `getStatus()` — отдельную JSON-копию статуса провайдера:
источник/transport, доступность SDK-анализатора, ошибки чтения, счётчики кадров/клиентов, возраст и свежесть данных.
При пропаже AudioCore эффекты останавливаются и восстанавливаются после его возвращения.
Проверка подписки PulseSync для Cover/Tweaked сохранена; отказ включает стандартный режим без изменения сохранённого выбора.

Исполняемые script/iframe из изолированного addon запрещены хостом. Инъекций, eval и обхода защиты нет.
Оформление DOM заголовков работает внутри Visual.
Прежние main-world обработчики колеса/взаимодействия модального окна и захват detached офлайн-аудио из JS темы больше не запускаются.
SDK-звук работает; для прежнего офлайн-PCM пути нужна поддержка хоста. Нельзя обещать его работу только на основании FFT обычного трека.
Нейронный статус не выдумывается: текущий публичный канал честно сообщает `analysis: spectrum`, `neuralAvailable: false`.

## Проверки

После сборки: `yarn test:integration` в Visual — два изолированных мира, собственные настройки Visual,
CSS-only тема, оба fullscreen-режима, premium fallback, отказ/возврат анализатора, перезапуск AudioCore, смена темы и cleanup.
Фикстура запрещает создание исполняемых script/iframe, как реальный хост.
`node scripts/check-lyrics-beat.mjs` проверяет перенесённую анимацию текста;
`node scripts/check-premium-obfuscation.mjs` — сохранённую проверку подписки.
Общие браузерные проверки могут сохранять артефакты в /tmp; не накапливайте профили Chrome.
