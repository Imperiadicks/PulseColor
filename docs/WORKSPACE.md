# PulseColor — четыре отдельных проекта

```text
PulseColorAudioCore/  PCM, общий планировщик, FFT, анализ голоса и нейронные модели
PulseColorVisual/  раскраска, волна и анимации страниц
Cover-Tweaked/     отдельный фуллскрин: Cover2Anim, Tweaked, текст и управление
PulseColor/        CSS-тема, оформление и все настройки
```

Зависимости: **PulseColor → PulseColorVisual + Cover-Tweaked → PulseColorAudioCore**.
PulseColorVisual больше не запускает Cover2Anim/Tweaked. Все настройки остаются в теме.
У каждого проекта собственные `package.json`, `src/`, `addon/`, `vite.config.ts`,
скрипты разработки и `dist/<id>/`. Сборка одного аддона не собирает остальные.
Исходники из соседнего проекта не попадают в его сборку.
Интеграционные проверки требуют всех четырёх каталогов рядом.

Из любого проекта: `yarn install`, `yarn typecheck`, `yarn test`, `yarn build`.
`yarn dev` обновляет только этот аддон; `yarn build:sync` собирает и устанавливает только его.

Все четыре: `node build-all.mjs`. Собрать и установить: `node build-all.mjs --sync`.
Команды работают на Linux и Windows (на Windows Yarn запускается через `cmd.exe`).
Нужен Yarn Classic 1.22.x; перед первой сборкой выполните `yarn install` в каждом
из трёх каталогов. На Windows переходите в папку проекта через `cd /d "путь\к\PulseColor"`,
а не запускайте установку зависимостей из `C:\Windows\System32`.
Сначала заканчиваются все сборки, затем устанавливаются PulseColorAudioCore, Visual и тема.
Для релиза нужны три пакета из трёх каталогов `dist`.

Если волна видна, но не реагирует на звук: [одна диагностическая запись](AUDIO-DIAGNOSTICS.md).
Сценарий `diagnose-audio.js` читает статусы обоих изолированных аддонов из `top`.
Проверки отказов аудио и восстановления: `yarn test:integration` в PulseColorVisual.

Оформление кнопок, текста, карточек и меню перенесено из Colorize 2 в
`PulseColor/assets/css/colorize2-visual.css`. Семейства классов сопоставляются без
привязки к хешам ЯМ. Цвета контролов и их состояния принадлежат теме; Visual
больше не накладывает поверх них собственный стеклянный UI. Фон, палитра волны,
рендер и геометрия переходов остались PulseColor. Сравнение с соседними исходниками
Colorize 2: `node scripts/check-colorize2-visual.mjs` из PulseColorVisual.

ID темы сохранён; ID прежнего PulseColor Runtime сохранён у PulseColorVisual.
Нейросервис получил новый ID. Все настройки находятся у темы PulseColor.
При первом обновлении текущие значения из Visual переносятся в тему, даже если у неё
остался более старый файл настроек. Последующие установки сохраняют изменения темы.
Тема публикует ограниченный канал настроек; оба web-addon читают его без доступа к чужому хранилищу.
В PulseSync включите оба script-аддона и выберите тему PulseColor.

Модели находятся **только** в PulseColorAudioCore. Скрипт темы публикует настройки, но не запускает движки.
Визуальные эффекты и анализ запускаются при выбранной теме PulseColor; нейронные вычисления
дополнительно требуют реально смонтированного потребителя. Само наличие включённого
нейросервиса не означает постоянную работу моделей.

При замене темы оба движка останавливаются по изменению её CSS, даже если PulseSync
оставил web-addon и скрипт темы включёнными. Убираются волна, эффекты, палитра и подписки
движков. Остаются только наблюдатели возвращения темы; при повторном выборе PulseColor
движки запускаются снова. Наблюдение за стилями не реагирует на аудиокадры и обычную
перестройку страницы. Проверка замены/удаления CSS, media и загрузки другой темы:
`node scripts/check-web-addon.mjs` из PulseColorVisual (после сборки всех четырёх проектов).
